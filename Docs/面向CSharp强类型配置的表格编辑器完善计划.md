# 面向 C# 强类型配置的表格编辑器完善计划

> **Created:** 2026-04-23
> **Status:** 规划中
> **定位:** 在现有工作区浏览和只读表格基础上，演进为完整的 C# 强类型配置表格查看/编辑器

---

## 一、目标定义

DataConfigEditor 的最终目标是：

> **做一个面向 C# 强类型配置的表格化查看/编辑器。**

它不是通用 Excel，也不是 C# IDE。它要借鉴 Excel、VS Code 和成熟桌面软件的工作流，但所有功能都围绕 C# 配置数据展开：

- C# 属性是列 schema。
- `/// <summary>` 是中文说明。
- `public static readonly` 实例是数据行。
- enum / Flags enum / bool / 数值 / 路径字符串决定单元格编辑器。
- 对象初始化器是保存回写边界。
- 诊断视图说明哪些源码不能稳定表格化。

现有代码已经实现了工作区目录树和基础表格查看，但还处于原型阶段。后续重点不是继续堆零散按钮，而是把“工作区、表格、设置、编辑、保存、诊断”做成一致的产品结构。

执行步骤与开发者验收见 [面向 C# 强类型配置的表格编辑器方案执行文档](./面向CSharp强类型配置的表格编辑器方案执行文档.md)。

## 二、当前实现问题

### 2.1 已具备能力

- 左侧可以打开工作区目录。
- 左侧可以显示文件夹和 `.cs` 文件。
- 点击 `.cs` 文件后，右侧可以显示基础表格。
- 表头已经可以显示字段名和 `<summary>` 注释。
- 已接入“源码 + DLL 补语义”的混合解析：源码决定表格骨架和写回边界，DLL 补充 enum、数值、bool 等类型信息。
- enum 单元格已支持显示成员名，表头 tooltip 可显示类型和枚举项。
- 已支持列级筛选入口：enum 多选筛选、数值比较筛选、文本基础筛选。
- 有基础设置入口，可调顶部留白、字体、行高、列宽等。

### 2.2 主要问题

| 问题 | 现象 | 要求 |
|------|------|------|
| 文件树不可隐藏 | 所有文件夹都会显示，不能像 VS Code 那样隐藏无关目录 | 支持隐藏目录/文件规则，持久化保存 |
| 表格位置不统一 | 某些表格太靠上，右侧空白和表格锚点显得随机 | 所有表格使用统一布局规则 |
| 设置太碎 | 设置藏在下拉菜单里，需要一个个点 | 重构为设置面板，支持预览和应用 |
| 表格功能不足 | 只读表格，缺少筛选、排序、多选、批量编辑 | 按成熟表格软件补齐核心交互 |
| 编辑语义不足 | 当前单元格只是文本显示 | 按 C# 类型选择编辑器和校验 |
| 诊断不足 | 不知道为什么某些文件/字段不能编辑 | 文件、列、单元格都要有诊断 |

## 三、主界面规格

采用“工作区 + 单表主视图”作为主结构。

```text
┌───────────────────────────────────────────────────────────────┐
│ 菜单/工具栏：打开目录 保存 撤销 重做 筛选 批量编辑 设置 诊断     │
├───────────────┬───────────────────────────────────────────────┤
│ 工作区目录树   │ 当前 .cs 文件对应的一张配置表                  │
│               │                                               │
│ Ability       │ ┌──────┬────────┬────────────┬────────────┐   │
│  Ability...cs │ │实例名│ Name   │ Cooldown   │ TriggerMode │   │
│ Feature       │ │     │ 名称   │ 冷却时间    │ 触发模式    │   │
│ Unit          │ ├──────┼────────┼────────────┼────────────┤   │
│               │ │Dash │ 冲刺   │ 1.0f       │ Manual      │   │
│               │ │Slam │ 裂地...│ 3.5f       │ Auto        │   │
│               │ └──────┴────────┴────────────┴────────────┘   │
├───────────────┴───────────────────────────────────────────────┤
│ 状态栏：当前文件 修改状态 筛选行数 诊断数量                     │
└───────────────────────────────────────────────────────────────┘
```

第一版不做多文档 IDE。多页签、右侧详情面板、跨表编辑可以后续加入，但不能阻碍单表体验先完成。

## 四、工作区目录树

### 4.1 基本行为

- 左侧显示文件夹和 `.cs` 文件。
- 文件夹支持展开/折叠。
- 点击 `.cs` 文件打开表格或诊断视图。
- 当前打开文件高亮。
- 工作区根目录显示真实目录名。
- 打开新工作区后记入最近目录。

### 4.2 隐藏规则

参考 VS Code 的 `files.exclude` 思路，增加工作区隐藏规则。

默认隐藏：

- `bin/`
- `obj/`
- `.godot/`
- `.git/`
- `.idea/`
- `.vscode/`
- `.history/`
- `.superpowers/`
- `*.uid`
- 非 `.cs` 文件

可配置规则：

```json
{
  "workspace.excludePatterns": [
    "**/bin/**",
    "**/obj/**",
    "**/.godot/**",
    "**/*.uid"
  ]
}
```

交互要求：

- 文件夹右键菜单支持“隐藏此文件夹”。
- 文件右键菜单支持“隐藏此文件”。
- 设置面板中可以编辑隐藏规则列表。
- 工具栏提供“显示隐藏项”开关，打开后隐藏项以灰色显示，便于恢复。
- 隐藏规则只影响 DataConfigEditor，不修改项目 `.gitignore`。
- 隐藏规则分为全局默认规则和工作区规则。

验收标准：

- 打开 DataNew 时，只看到对配置工作有价值的目录和 `.cs`。
- 隐藏某个文件夹后，刷新/重启仍保持隐藏。
- 打开“显示隐藏项”后能看到被隐藏项，并能恢复。

## 五、表格布局规格

### 5.1 统一布局

右侧表格区域必须使用统一布局，不允许不同文件因为行数或列数不同而出现“漂在上面”的不一致感。

规则：

- 表格容器永远填满右侧可用区域。
- 表格左上角与右侧内容区保持固定边距，默认 8px。
- 表头固定在顶部。
- 实例名列固定在左侧。
- 表格右侧和下方允许空白，但表格自身不能只占一个小框后脱离主区域。
- 横向滚动条贴近表格区域底部，而不是漂在窗口中间。
- 空表、诊断视图、加载失败视图都使用同一套内容锚点。

当前截图中某些表格太靠上，本质是布局和表格容器高度没有统一。后续应把“表格主区域”作为固定布局对象，而不是按内容高度自然收缩。

### 5.2 表头

表头使用两层信息：

```text
Name
名称
```

规则：

- 第一行是 C# 属性名，英文，来自源码字段。
- 第二行是中文说明，来自紧邻属性的 `<summary>`。
- 没有 `<summary>` 时只显示英文属性名，并给出弱诊断。
- 表头高度固定或按最大两行高度统一，不因单列中文换行导致整表跳动。
- 表头支持 tooltip，显示完整类型、注释、默认值、是否可编辑、来源文件。

### 5.3 行列

- 第一列是实例名，来自静态字段名。
- 行 tooltip 显示实例 `<summary>`。
- 属性列顺序按源码顺序。
- 继承属性排在子类属性之前，并用分组/来源提示区分。
- 支持“行=实例 / 行=属性”切换，但默认是行=实例。

### 5.4 分组

分组来自：

```csharp
// ====== 基础信息 ======
```

显示策略：

- 第一阶段可先用列背景、表头边界、分隔线表示分组。
- 后续支持列组折叠。
- 分组折叠状态按文件保存。

## 六、表格查看能力

### 6.1 筛选

筛选必须是核心能力，不是后续装饰。

功能：

- 每列表头有筛选入口。
- 支持文本包含、等于、不等于、为空、不为空。
- 数值列支持大于、小于、区间。
- bool 列支持 true/false。
- enum 列支持多选枚举值。
- 多列筛选叠加。
- 状态栏显示 `显示 8 / 共 11 行`。
- 工具栏提供“清除筛选”。

编辑规则：

- 筛选后批量编辑只作用于当前选中的可见单元格。
- 隐藏行不应被误改。

### 6.2 排序

- 点击表头排序。
- 支持升序、降序、恢复源码顺序。
- 数字按数值排序，文本按文本排序，enum 按声明顺序或显示名排序。
- 排序只影响视图，不改变源码实例顺序，除非后续明确提供“按当前排序重排源码”命令。

### 6.3 查找与定位

- 支持当前表内搜索。
- 搜索范围包括实例名、属性名、中文注释、单元格值。
- 支持下一个/上一个。
- 搜索结果高亮。
- 后续可加全工作区搜索。

### 6.4 列管理

- 手动调整列宽。
- 自动适配列宽。
- 冻结实例名列。
- 隐藏列/显示列。
- 按分组隐藏列。
- 列宽、隐藏状态、排序状态可按文件记忆。

## 七、编辑能力

### 7.1 编辑状态

表格必须明确区分：

- 可编辑单元格。
- 只读单元格。
- 可显示但不能安全回写的表达式。
- 类型错误单元格。

不能把所有内容都当普通字符串随便改。每个单元格的编辑器来自 C# 属性类型。

### 7.2 类型化单元格

| C# 类型 | 编辑器 | 校验 |
|--------|--------|------|
| `string` / `string?` | 文本框 | 字符串转义、null |
| 数值 | 数值输入 | 范围、格式、后缀 |
| `bool` | 复选框 | true/false |
| enum | 下拉框 | 成员必须存在 |
| Flags enum | 多选弹窗 | 组合值合法 |
| 路径字符串 | 文本框 + 选择按钮 + 预览 | 路径存在性、`res://` 映射 |
| 简单列表 | 文本/弹窗编辑器 | 后续支持 |
| 嵌套对象 | 只读或弹窗编辑器 | 后续支持 |

### 7.3 批量编辑

必须支持：

- 多选连续区域。
- Ctrl 多区域选择。
- 选中多个同类型单元格后输入一次，批量写入。
- 批量编辑前做类型兼容检查。
- 批量编辑结果进入同一个撤销步骤。
- 对筛选后的可见行批量编辑时，不影响隐藏行。

### 7.4 复制粘贴

- 支持从表格复制到剪贴板。
- 支持从 Excel/文本粘贴回表格。
- 粘贴时按目标单元格类型校验。
- 部分失败时给出清单，不静默跳过。

### 7.5 撤销重做

- 单格编辑、批量编辑、粘贴、清空、路径选择都进入撤销栈。
- 撤销/重做后状态栏和修改标记同步更新。
- 保存后撤销栈保留，但修改状态根据当前内容和保存快照判断。

## 八、保存回写

保存不是简单把表格转成新文件，而是尽量保留源码结构。

规则：

- 只回写可定位的对象初始化器赋值。
- 不执行用户代码。
- 不重排无关代码。
- 不删除注释。
- 不格式化整个文件。
- 只修改发生变化的属性赋值。
- 缺失属性赋值时可以插入，插入位置遵循属性顺序。
- 无法安全回写时阻止保存，并显示诊断。

保存入口：

- `Ctrl+S`
- 工具栏“保存”
- 关闭/切换文件时如果有未保存修改，提示保存、放弃、取消。

验收：

- 修改 `Name` 后，源码中对应实例初始化器的 `Name = ...` 被更新。
- 修改 enum 后，保存为 `EnumType.Member`。
- 修改 string 后，正确转义引号和反斜杠。
- 保存不改变无关行和注释。

## 九、设置系统重构

当前下拉菜单式设置只能作为临时方案，后续必须重构为设置面板。

### 9.1 设置入口

- 工具栏“设置”打开独立设置窗口或右侧设置面板。
- 设置按分类显示。
- 每个设置有名称、说明、当前值、默认值。
- 支持“应用”“确定”“取消”“恢复默认”。
- 点击“应用”后立即反映到当前表格，窗口不关闭。
- 点击“取消”恢复打开设置前的状态。

### 9.2 设置分类

应用设置：

- 主题：浅色/深色/跟随系统。
- 字体。
- UI 缩放。
- 最近目录数量。
- 启动行为。

工作区设置：

- 隐藏规则。
- 是否显示隐藏项。
- 默认打开目录。
- 是否记忆目录展开状态。

表格设置：

- 顶部/左侧边距。
- 行高。
- 表头高度。
- 固定列宽。
- 自动列宽策略。
- 是否冻结实例名列。
- 是否显示网格线。
- 是否显示中文注释副标题。
- 是否显示类型图标。
- 默认排序/筛选是否记忆。

编辑设置：

- 是否启用编辑。
- 保存前是否确认。
- 批量编辑前是否确认。
- 粘贴失败策略。
- 路径字段根目录映射。

诊断设置：

- 是否显示弱诊断。
- 是否在表头显示诊断标记。
- 日志级别。

### 9.3 设置存储

建议分两层：

- 全局设置：`%LocalAppData%/DataConfigEditor/settings.json`
- 工作区设置：工作区本地 `.dataconfigeditor/settings.json`

工作区设置不应默认提交到游戏项目仓库，除非用户明确想共享团队配置。后续可以提供“导出团队设置”。

## 十、诊断系统

诊断要成为产品核心能力。

层级：

- 文件诊断：不能表格化、找不到 class、没有实例、多个候选类。
- 类型诊断：找不到基类、找不到 enum、属性类型不支持。
- 单元格诊断：表达式不能求值、不能回写、类型不匹配。
- 保存诊断：定位失败、格式化失败、写入冲突。

显示：

- 不可表格化文件显示诊断视图。
- 可表格化文件在状态栏显示诊断数量。
- 表头/单元格用小标记提示诊断。
- 诊断面板列出完整清单，可点击定位。

## 十一、架构调整

### 11.1 必须拆清楚的模型

当前 `TableDocument` 需要扩展成能支撑编辑的模型。

建议模型：

- `TableDocument`：一张表的整体数据、来源、诊断。
- `TableColumn`：属性名、类型、注释、分组、可编辑性、来源。
- `TableRow`：实例字段名、实例注释、来源范围。
- `TableCell`：显示值、原始表达式、类型化值、可编辑性、诊断、源码定位。
- `TableViewState`：排序、筛选、列宽、隐藏列、选择区域。
- `EditOperation`：单次编辑或批量编辑，用于撤销重做。
- `WorkspaceSettings`：目录树隐藏规则和工作区偏好。
- `AppSettings`：全局 UI 和编辑偏好。

### 11.2 UI 层职责

UI 不直接解析 C#，只消费：

- `WorkspaceEntry`
- `TableDocument`
- `TableViewState`
- `SettingsViewModel`
- `DiagnosticViewModel`

### 11.3 Parser 层职责

Parser 只负责把 C# 受限配置形态转成文档模型：

- class / property / instance。
- summary 注释。
- 分组注释。
- enum / Flags。
- 源码定位。

后续从正则迁移到 Roslyn Syntax 时，UI 和编辑层不应大改。

## 十二、阶段计划与验收

后续允许 AI 按阶段直接推进实现。每个阶段完成后停下来让用户验收，不需要每个小按钮都询问。

下一阶段的可执行 superpowers 计划已经拆分到：

- [Strongly Typed Config Editor Next Phase Implementation Plan](./superpowers/plans/2026-04-23-strongly-typed-config-editor-next-phase.md)

它只覆盖 Phase 1 和 Phase 2 的第一批可验收内容：工作区隐藏、表格布局统一、设置面板重构。筛选、排序、搜索、编辑、保存回写应在该阶段验收后再生成独立执行计划。

### Phase 1：布局和工作区体验修正

目标：

- 表格区域统一布局，不再出现表格位置奇怪的问题。
- 工作区目录树支持隐藏规则。
- 当前打开文件、状态栏、最近目录体验稳定。

验收：

- 打开多个 `.cs`，表格都从同一位置开始并填满右侧区域。
- 隐藏 `Resource/` 或某个文件夹后，树立即更新。
- 重启后隐藏规则仍生效。

### Phase 2：设置系统重构

目标：

- 用设置面板替代下拉碎片设置。
- 支持应用/确定/取消/恢复默认。
- 设置变化可以马上预览。

验收：

- 打开设置面板，调整行高/字体/列宽，点击“应用”后当前表格立即变化。
- 点击“取消”能恢复进入设置前的状态。
- 隐藏规则能在设置面板中编辑。

### Phase 3：表格浏览能力完善

目标：

- 筛选、排序、搜索、列宽、隐藏列、冻结列。

验收：

- 多列筛选叠加正确。
- 清除筛选恢复全部行。
- 排序后不改变源码顺序。
- 搜索能定位实例名、属性名、注释和值。

### Phase 4：类型系统增强

目标：

- 工作区索引 enum、Flags、基类。
- 表头显示类型和诊断。
- 单元格知道自身类型。

验收：

- enum 列能显示下拉候选。
- 继承属性能显示。
- 找不到 enum/基类时有明确诊断。

### Phase 5：编辑和批量编辑

目标：

- 单格编辑。
- 类型化编辑器。
- 多选批量编辑。
- 复制粘贴。
- 撤销重做。

验收：

- 修改 string、数字、bool、enum 都能校验。
- 多选同类型单元格可批量赋值。
- 批量编辑可以一次撤销。
- 粘贴表格数据时错误单元格有提示。

### Phase 6：保存回写

目标：

- 修改后的值安全回写到 `.cs` 对象初始化器。
- 保存前后有修改状态。
- 无法安全保存时给诊断。

验收：

- 保存只改动目标赋值。
- 注释、分组、无关代码不被破坏。
- 无法定位的单元格不允许静默保存。

- 行=属性布局。
- 多页签。
